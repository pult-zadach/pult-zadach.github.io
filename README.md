# Пульт задач

Планировщик задач, целей и напоминаний по нескольким рабочим проектам. Каждая запись получает индекс **важность·срочность** (шкала 1–5), цвет по матрице Эйзенхауэра и место в списке «Сегодня».

Работает в браузере, ставится на iPhone как приложение. Данные хранятся только на устройстве пользователя, сервера нет.

## Возможности

- Индекс `В·С` и балл В × С (до 25). Квадранты: «Сделать сейчас», «Запланировать», «Делегировать», «Отложить».
- Автосрочность: за 3 дня до срока срочность не ниже 4, в день срока и после него 5.
- Экраны: Сегодня, Матрица (перетаскивание меняет индекс), Проекты (вложенные, с целями и прогрессом), Календарь.
- Быстрый ввод одной строкой: `Сверить сетку #звезда !4/5 завтра 15:00 @за 2ч`.
- Напоминания, пока приложение открыто; пропущенные показываются при открытии. Кнопка «В календарь iPhone» выгружает срок с будильником в `.ics`.
- Свайп вправо — готово, влево — на завтра. Сохранение и загрузка копии данных (JSON).

## Как установить на iPhone

1. Откройте адрес сайта в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Запустите «Пульт» с иконки и разрешите уведомления.

## Устройство проекта

| Файл | Что это |
|---|---|
| `src/app.html` | Исходник: вся разметка, стили и логика. **Правки вносятся здесь.** |
| `index.html` | Готовая страница сайта, собирается из `src/app.html`. Руками не править. |
| `build.ps1` | Сборка: `powershell -NoProfile -File build.ps1` (с ключом `-Icons` перерисует иконки). |
| `sw.js` | Service worker: офлайн-режим и открытие приложения по уведомлению. |
| `manifest.webmanifest`, `*.png` | Манифест и иконки для установки на телефон. |

Данные лежат в `localStorage` под ключом `pult.v1`. Если меняете формат данных, повышайте номер версии и пишите перенос старых данных в `load()`.

После изменения `sw.js` или списка файлов поменяйте `CACHE` в `sw.js` (например, `pult-v2`), чтобы у пользователей обновился офлайн-кэш.

## Как участвовать в разработке

1. Заведите бесплатный аккаунт на [github.com](https://github.com).
2. Попросите владельца добавить вас в соавторы (Settings → Collaborators) или сделайте форк и присылайте pull request.
3. Правьте `src/app.html`, пересобирайте `index.html` через `build.ps1`, проверяйте локально и отправляйте изменения. Сайт на GitHub Pages обновляется сам через 1–2 минуты.

Удобно работать через Claude Code: откройте папку репозитория и опишите, что нужно поменять.
